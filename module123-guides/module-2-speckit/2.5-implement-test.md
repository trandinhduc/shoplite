# 2.5 - Implement và Test

**Thời lượng:** 45 phút · **Kết quả:** tính năng mã giảm giá chạy được, `npm run check` và E2E pass.

## Bước 1 - Implement theo từng phase (20')

Không nên implement "một phát ăn ngay" toàn bộ: chạy theo phase để review từng phần.

```text
/speckit-implement Chỉ thực hiện Phase 1 và Phase 2.
```

Review `git diff`, chạy `npm test`. Ổn rồi tiếp:

```text
/speckit-implement Thực hiện Phase 3 (User Story 1 - MVP). Viết test trước, chạy cho fail, rồi mới cài đặt.
```

Kiểm tra MVP trên trình duyệt trước khi đi tiếp, sau đó:

```text
/speckit-implement Thực hiện các phase còn lại.
```

Trong lúc agent làm việc, quan sát:

- Task trong `tasks.md` được đánh dấu `[X]` khi xong.
- Các hook từ Module 1 vẫn hoạt động: file được format tự động, `quality-gate` bắt agent sửa khi test fail.
- Agent có dừng lại hỏi khi gặp điểm chưa rõ không?

> 💡 Mặc định mode `default` sẽ hỏi trước mỗi lần sửa file. Có thể `Shift+Tab` sang `accept edits on`
> để agent làm nhanh hơn - bạn vẫn review bằng `git diff` sau mỗi phase.

## Bước 3 - `/speckit-converge` (5')

```text
/speckit-converge
```

Lệnh đối chiếu code thật với spec/plan/tasks, phân loại khoảng trống: _missing_, _partial_,
_contradicts_, _unrequested_. Nếu còn thiếu, nó thêm một phase `## Phase N: Convergence` vào cuối
`tasks.md` (chỉ ghi thêm, không xóa). Nếu đủ, nó báo `✅ Converged`.

Còn task mới → `/speckit-implement` phase đó → `/speckit-converge` lại cho tới khi hội tụ.
